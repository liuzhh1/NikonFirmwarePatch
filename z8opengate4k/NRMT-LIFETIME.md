## 原厂队列与writer复制点

在上述126项基线上新增14项检查，完整回归为140项通过、无跳过。8项执行原厂队列/消费/清理，5项执行writer缓冲准备/完成/拒绝及普通4K与8K回退，1项核对17段原厂窗口。队列存储、链表、复制调用与原厂消费任务均执行，锁、堆分配、时间/状态、memcpy/memset辅助API、图像提交及存储接口使用有界替身。没有执行RTOS并发、TICO、物理写卡或文件关闭。

| 原厂阶段 | 实际执行与身份约定 |
|---|---|
| 0x40CA3154，任务队列0xA031C1718 | 原厂初始化为两阶段、60项、每项0xA8；复制整个任务，保留NRMT指针 |
| 0x40D20770 | 任务从阶段0转至1；0x38字节NRMT描述符复制到0xA031C17D8独立队列 |
| 0x40D1EA48，事件位6 | 输出消费任务将最多三个元数据包按顺序放入writer任务+0x38/+0x40/+0x48，长度在+0x50/+0x54/+0x58 |
| 0x40D22AD4 | 0x88字节writer任务再复制到两阶段、130项的0xA031C3098队列；原包指针仍在 |
| 0x40D20FD8，事件位8 | writer消费任务，内部模式2在0x40D21A5C调用复制辅助API，将NRMT字节复制到提供的输出缓冲 |
| 0x40D21B8C→0x40D1767C | 向存储接口提交三个缓冲；本轮在接口处捕获，接口本体未执行 |
| writer事件位9→0x40D231E0 | 注入存储完成事件后移除阶段1任务并清除busy；不代表真实存储完成或close |

控制中三个输出缓冲各1536字节：前1024为原厂生成的候选参数包，余512为合成载荷。writer按原协议把首4字节总长改成1536，其他参数字节完整保留，高度2756/有效4128×2752仍在；载荷未改变。缓冲不是有效TICO帧，模式2及编码完成描述符为测试输入，未据此认定真实NRAW会话已接通。

队列会复制描述符，不复制其所指的参数字节；移除任务只释放并清空描述符槽，不清空NRMT包。writer复制后，再强制生成60个普通包使原NRMT槽复用，输出缓冲仍保持不变。相反，绕过调度使槽在复制前复用，队列仍指向同一地址而内容已变。这证明需要在writer复制之前保持原包生命周期，不证明原厂固件实际违反此要求。满队列拒绝发生在生成之后，仍需追踪调用方调度/背压，不能以队列容量相同替代证明。

清理函数0x40D1FA58复位四个录制队列，保留NRMT原包和环形索引；没有把清理当成文件关闭。存储接口拒绝时保留待完成任务，并走原错误/事件分支。本轮没有改变固件字节或增加钩子，所有MAIN哈希及原writer保持原值。最新指针、尺寸、输出哈希、窗口及限制见[队列/writer记录](../docs/data/opengate4k-nrmt-queue-writer.json)；可用完整输入运行`python -B -m unittest discover -s tests -p test_opengate4k_nrmt_queue.py -v`复核。

## 原厂会话构造与保留末项停止协议

接入原厂0x40727A18配置构造器，以请求及配置输入属性生成0x90字节记录，经0x40D1CFF4写全局记录，再由0x40D1FF60和0x40D228A8分别传给record/writer。配置输入属性+0x20的类型6映射内部模式2，类型5映射1；不推定此属性对象与NCTG工作副本属于同一对象。请求首字段为1/2时生成配置+0x58=1，0/3时为0。请求种类与输入属性仍是测试提供，上层真实录制选择尚未验收。

配置+0x58开启时，0x40D20770在运行期间保留最后一项；停止后重复该描述符，以补齐三项组。本轮没有注入新的NRMT包或强制flush成功。原“6项尾部”控制在全部分发后才开启保留模式，末项已不在输入阶段0队列，所以无法重复；这个负例继续保留。请求种类1从开始构造会话后，9项控制先保留1项、阶段1剩5项，7次停止推进后进入任务状态2，9份参数正文/合成载荷保持原顺序，NRMT环形索引未变化。
