# NRMT 调用内身份实验层

在原厂参数生成函数入口捕获本次4K选择，后续编码高度及有效裁切回调从调用栈读取身份。生成期间切换模式不会重新解释本次参数。**生成的是候选参数，不是TICO编码帧或NEV文件。** 原生参数缓冲的消费、完整文件关闭和实机录像仍未验收。

| 原厂路径 | 栈与参数约定 |
|---|---|
| 0x410A4FC4 | 原0xD0字节帧；x0请求、x1源快照、x2附加参数、x3输出描述符 |
| 0x410A5418→0x410A541C | 遍历20个NRMT创建回调，编码高度回调为0x410A58E4 |
| 0x410A6334→0x410A6344 | 第19个回调增加0x10字节帧并调用嵌套生成器 |
| 0x410A6470→0x410A64BC | 0x40字节帧，遍历13个子记录；裁切回调为0x410A6C88 |
| 原生保存的x30 | 主帧+0xC8，嵌套帧+0x38，前缀帧+0；逐层核对后才读取新增记录 |

新增48字节栈记录包含源指针、64位标记、帧率、目标状态和请求类型。只有原厂请求4、Video/FX/readout8快照、4K低帧率、当前格式/尺寸/帧率及已安装OG几何一致时锁存目标。生成器完整执行原厂函数体；新高度/裁切入口核对调用链及源身份，不再读菜单。普通调用显式保留非目标状态；返回时清除记录，原结果和父帧恢复。未分配新的全局状态，也未占用原厂结构空位。

新增代码固定在0x4096E000、800字节，SHA-256为`7bfb1353cf6ae7a518c1bab3421b02c66ec5c6152f95023692fa0802d989a782`。原厂帧、回调表及原生环形缓冲协议由8段窗口哈希固定；源码、机器码和帧约定由独立profile核验。新增层替换原录制层两个NRMT入口及生成器首指令，保留原D10、NCTG副本层、原厂函数体和writer-close。

```sh
python tools/build_opengate4k_lab.py \
  --original /path/to/stock/Z_8_0311.bin \
  --baseline /path/to/reviewed-03.11.p0.bin --compiler /path/to/clang \
  --experimental-recorder --experimental-playback \
  --experimental-nctg-lifetime --experimental-nrmt-lifetime \
  --output build/opengate4k/nrmt-scope-001
```

`--experimental-recorder`是必须项，回放和NCTG副本层均可选。只启用新增开关时拒绝构建；未启用时，所有旧阶段MAIN哈希保持不变。构建仍只输出模拟器MAIN，不生成相机更新包。

本轮126项项目测试全部通过，无跳过，包含70项AArch64执行和19项完整输入构建检查。新增25项测试：8项栈与身份检查、8项以完整MAIN执行原厂生成器、5项原厂提交边界执行、4项完整输入构建检查。原厂生成器的20个主回调及13个嵌套回调均执行；13个外部辅助入口采用有界数学、校准、字符串等固定值替身，真实曝光、日期、帧率与校准元数据不属于本轮验收。测试中源快照、被调用者寄存器、栈、提前返回及8K/普通模式回退均核对。

固定输入的候选参数包长1024字节；高度为`0000000ac4`（2756），子记录中的有效区域为4128×2752。与普通4K包相比只改变72、73、598、599四个字节。生成期间在编码高度前或高度与裁切之间切换菜单，候选包与稳定选择时逐字节一致；普通调用也不会被后来开启的OG提升为候选。

进一步实际执行原厂提交函数0x40D200FC到队列API边界。准备的0xA8字节任务块在+0x68保存0x38字节描述符副本，参数包指针仍在任务块+0x80；本层没有改变这个协议。状态0/3、零批次和超过60任务的批次被原厂分支拒绝；30×2任务被接受，重复标记顺序和队列拒绝时的错误/事件路径已核对。锁、队列和事件API使用有界替身，没有执行操作系统队列和编码消费者；因此这些结果只证明提交函数的准备/分支行为，不证明参数已经消费或文件已经关闭。

栈记录仅保持本次调用身份。进入生成器前已变化的选择、源快照并发修改、原生环形缓冲被消费的时限、它与NCTG副本的文件身份关联，以及Stop/真实文件I/O/close仍需另外验证。TICO、物理读出、代理码流、i菜单/取消和完整QEMU录制尚未验收。本轮没有重跑旧9项模型/触点检查。
